# ROMA AETERNA — MULTI-PAGE BUILD

Upload all files in this package to the root of the existing `roma-aeterna` GitHub repository, replacing the previous one-page build.

The new build includes:
- cinematic landing page
- emperor index and dedicated pages for indexed major/minor emperors
- eras index and dedicated era pages
- dynasty index and dynasty pages
- Enemies of Rome index and dedicated enemy pages
- Army, Religion, Society, Cities, Architecture, Coins, Art, Wars, Maps, Latin, Archaeology and Sources pages
- image credits
- responsive navigation and layout

Images use Wikimedia Commons' Special:FilePath endpoint with a Wikimedia Commons API fallback when a curated filename cannot be resolved.
