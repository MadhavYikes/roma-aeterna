## Files
- index.html — site

- app.js — data, search, filters, profiles, maps and interactions
- credits.html — image provenance page
- CREDITS.json — image source registry
- README.md — project notes

## Publish
This is a static site. Put all files in the root of a GitHub repository and enable GitHub Pages.

GitHub Pages can publish a repository as a website and supports a custom domain.

## Custom domain
Recommended production path:
1. Buy a domain such as `roma-aeterna.com` if available.
2. Create a GitHub repository named `roma-aeterna`.
3. Upload every file in this package.
4. Settings → Pages → deploy from the main branch.
5. Settings → Pages → Custom domain → enter your domain.
6. Configure the DNS records shown by GitHub at your registrar.
7. Enable HTTPS after DNS has propagated.

## Image licensing
The site now includes a dedicated image-credit page and source registry. Before commercial publication, verify each listed Commons file's current author/license and add the exact required attribution/license text to CREDITS.json. Wikimedia Commons explicitly notes that individual files can have different licensing and attribution requirements.
