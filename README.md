# ROMA AETERNA — COMPLETE STATIC SITE

This package is the expanded, finished static build of Roma Aeterna.

## Included
- Imperial / monumental visual identity
- Responsive desktop / tablet / mobile layout
- Emperor database with major and minor rulers
- Emperor search
- Dynasty filter
- Individual emperor modal profiles
- Dynasty section
- Coin gallery
- Roman art and architecture gallery
- Roman army section
- Wars and campaigns
- Interactive schematic map selector for 27 BC, 117 AD, 284 AD, 395 AD and 476 AD
- Rome/Forum feature
- Imperial timeline
- Sources/further-reading section
- Keyboard-accessible emperor modal
- Mobile navigation
- Scroll progress indicator
- No framework or build step required

## Run
Open index.html.

## Deploy
Upload index.html, style.css and app.js to a static host such as GitHub Pages, Cloudflare Pages, Netlify or Vercel.

## Important image/licensing note
The site requests images from Wikimedia Commons' Special:FilePath endpoint. This is convenient for a prototype, but individual Commons files can have different licenses and attribution requirements. Before commercial publication, replace/lock the image set against specific Commons file pages and preserve required attribution.

## Recommended production improvements
- Replace dynamic Wikimedia FilePath requests with a curated local image manifest.
- Add individual source/credit links for every image.
- Add more emperor records, provincial pages and inscriptions.
- Replace the schematic maps with historically sourced GIS layers.
- Add structured metadata / Open Graph images.
- Add analytics and a privacy notice only if analytics are actually enabled.
